# Testele de matematică, pe lecție

Itemii vechi rămân în `practiceBank.js`, `exerciseBank.js` și `exerciseExtras.js`. Au `lesson` și `level` explicit. Itemii noi ai unui capitol stau aici, câte un fișier, și se adaugă la bancă fără să schimbe cheile capitolului.
